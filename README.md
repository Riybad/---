# نبغ — النخب الناشئة (تمكين)

نظام ويب عربي فيه قسمان:

1. **خطط الطلاب** — كل طالب يسجّل اسمه ويقسّم المقررات على لقاءات السنة بين **حفظ** و**شرح**، وتُحفظ الخطة عندك في قاعدة بيانات تصدّرها إكسل.
2. **الإدارة المالية** — الإيرادات والمصروفات والعهد (الموجودة من قبل).

## خطط الطلاب

### كيف يقسّم الطالب؟

الرابط العام `‎/khitta‎` — بلا حساب ولا كلمة مرور:

المقررات **دراسة ذاتية** — لا علاقة لها بلقاءات الدفعة، فالتقسيم على وحدة زمنية يختارها الطالب نفسه.

1. **التعريف** — الاسم (والجوال اختياري)، ثم يختار وحدة التقسيم: **يوميًا** (366 يومًا) أو **أسبوعيًا** (53 أسبوعًا) أو **شهريًا** (13 شهرًا هجريًا).
2. **اختيار المقرر** — «بأي مقرر تحب تبدأ؟».
3. **التقسيم** — لكل مقرر مساران بحجمين مستقلين (**الحفظ** و**الشرح أو القراءة**)، يحدّد لكل مسار كم يأخذ في اليوم/الأسبوع/الشهر بأزرار − و + أو بشريط سحب، أو بأزرار جاهزة: **على مهل / متوازن / مكثّف**. تظهر له فورًا: كم فترة يحتاج، ومتى يبدأ وينتهي بالهجري والميلادي.
4. يرجع ويختار المقرر التالي. **المقررات متتابعة لا متوازية** — الطالب لا يدرس مقررين في وقت واحد، فكل مقرر يبدأ حيث انتهى الذي قبله، والترتيب هو ترتيب اختياره. المعدّل الافتراضي يتناسب مع حجم المقرر (التاريخ بـ750 صفحة يأخذ نصيبًا أكبر من متن بـ154 بيتًا) حتى تسع المقررات الخمسة السنة.
5. **المراجعة والحفظ** — يشوف جدول السنة كامل ثم يحفظ، فيحصل على **رابط خاص بخطته** يرجع له وقت ما شاء ويحمّل منه ملف إكسل.

شريط السنة أعلى الشاشة يوضّح ما استهلكه وما بقي — ملوّن بلون كل مقرر.

### التقويم

الخطة تغطي **السنة كاملة** كما في **الخطة الزمنية لتمكين 48** (`docs/الخطة-الزمنية.xlsx`): من 8 ربيع الأول 1448هـ إلى 19 ربيع الأول 1449هـ (366 يومًا)، بالتاريخين الهجري والميلادي.

أحداث السنة (لقاءات تمكين، الأيام القرآنية، عرض المحفوظ، المبيت، الملتقيات، الإجازات، الدورة المكثفة، النادي الصيفي…) محفوظة كما هي: تظهر في صفحة **الخطة الزمنية** في اللوحة بألوان الملف الأصلي، وتُذكر في عمود «أحداث الفترة» في ملف الإكسل حتى يعرف الطالب ما الذي يصادف خطته.

بيانات التقويم مُستخرجة من الملف إلى `src/lib/calendar-data.ts` عبر `scripts/extract-calendar.py` (يُعاد تشغيله فقط لو تغيّر الملف).

### في اللوحة (تحتاج تسجيل دخول)

| الصفحة | الوظيفة |
|---|---|
| **الطلاب** | قائمة الطلاب ووحدة تقسيم كل واحد، بحث بالاسم أو الجوال، ولكل طالب صفحة فيها خطته كاملة + ملاحظات المشرف + رابط خطته + تصدير إكسل + حذف |
| **المقررات** | تعديل اسم المقرر وفنّه ووحدته (بيت/باب/صفحة/درس/سؤال/حديث/فصل) وحجم كل مسار ومسمّى المسار الثاني، وإضافة مقررات جديدة أو إيقاف مقرر |
| **الخطة الزمنية** | تقويم السنة كاملًا بألوان الملف الأصلي (مرجع للأحداث — لا يدخل في تقسيم المقررات) |

### المقررات الخمسة

الأحجام من ملف «تفصيل مقررات الخطة الأساسية»:

| المقرر | الفن | الوحدة | الحفظ | المسار الثاني |
|---|---|---|---|---|
| سلم الوصول | العقيدة | بيت | 290 | شرح 290 |
| أخصر المختصرات | الفقه | صفحة | 299 | شرح 299 |
| نظم الآجرومية | اللغة | بيت | 154 | شرح 154 |
| القرآن سؤال وجواب | علوم القرآن | صفحة | 200 | قراءة 200 |
| موسوعة التاريخ الإسلامي | التاريخ | صفحة | 30 | قراءة 750 |

المساران مستقلان تمامًا — التاريخ يُحفظ منه 30 صفحة ويُقرأ منه 750. اجعل حجم أي مسار **صفرًا** من صفحة المقررات لإلغائه، وغيّر مسمّى المسار الثاني بين «شرح» و«قراءة».

### التصدير إلى إكسل

- **خطة طالب واحد — على القالب** (الافتراضي): نسخة من `docs/الخطة-الزمنية.xlsx` بألوانها ودليلها كما هي، وقد عُبِّئ فيها تحت كل شهر الصفّان الفارغان: الأول **الحفظ** والثاني **الشرح/القراءة**. خانات كل فترة مدموجة، واسم المقرر يظهر أول الشهر وكلما تغيّر المقرر. يُبنى بـ `exceljs` حفاظًا على التنسيق (`src/lib/template-xlsx.ts`).
- **خطة طالب واحد — جدول تفصيلي** (`?format=table`): 3 أوراق — ملخص الخطة، جدول الخطة (صف لكل فترة ومقرر مع أحداثها)، الخطة الزمنية.
- **كل الطلاب** (من اللوحة): 4 أوراق — الطلاب، تفاصيل الخطط (صف لكل فترة ومقرر، جاهز للـ Pivot)، المقررات، الخطة الزمنية.

كل الملفات باتجاه من اليمين لليسار وفيها التاريخ الهجري والميلادي معًا.

## الإدارة المالية

### المزايا

- **لوحة رئيسية**: مجموع الإيرادات، مجموع المصروفات، الصافي، وأعداد ومبالغ العهد (طلبات جديدة / مفتوحة / بانتظار الاعتماد / مقفلة).
- **الإيرادات والمصروفات**: إدخال يدوي + استيراد من ملف إكسل (مع نموذج جاهز للتحميل).
- **العهد**:
  - رابط عام ثابت ترسله لأي موظف يعبي فيه طلب العهدة (الاسم، الجوال، المرحلة، التاريخ الهجري، السبب، المبلغ المطلوب).
  - تصرف العهدة من اللوحة وتحدد المبلغ.
  - لكل عهدة رابط إقفال خاص ترسله للموظف، يدخل فيه تفاصيل كل فاتورة ويرفعها PDF.
  - تعتمد الإقفال أو تعيد الفتح إذا كانت الفواتير ناقصة.
- تسجيل دخول بكلمة مرور للمشرف فقط — الموظفون لا يحتاجون حسابات.

## التشغيل

```bash
npm install
cp .env.example .env   # وغيّر ADMIN_PASSWORD
npm run build
npm start              # يعمل على http://localhost:3000
```

للتطوير: `npm run dev`

## البيانات

- **محليًا** (بدون أي إعداد): قاعدة Postgres مدمجة (PGlite) في `data/pg`، وملفات الفواتير في `data/uploads/` — انسخ مجلد `data/` دوريًا كنسخة احتياطية.
- **على الاستضافة (Vercel)**: قاعدة بيانات Neon (مجانية) عبر `DATABASE_URL`، وملفات الفواتير في Vercel Blob عبر `BLOB_READ_WRITE_TOKEN` — كلاهما يُربط بنقرة من تبويب Storage في Vercel.

## النشر (مجانًا على Vercel)

الفرع الذي فيه منصة الطلاب هو `claude/course-distribution-platform-97sx6u`.

1. **استورد المشروع** — افتح [vercel.com/new](https://vercel.com/new) وسجّل بحساب GitHub، ثم اختر مستودع `Riybad/---` واضغط **Import**.
2. **اختر الفرع** — في صفحة الاستيراد وسّع **Git Branch** واختر `claude/course-distribution-platform-97sx6u` (أو ادمج الفرع في الفرع الرئيسي أولًا). ثم **Deploy**.
3. **اربط قاعدة البيانات** — من صفحة المشروع: تبويب **Storage** ← **Create Database** ← **Neon** (Free) ← **Connect**. يُضاف `DATABASE_URL` تلقائيًا.
4. **اضبط كلمة المرور** — تبويب **Settings** ← **Environment Variables** ← أضف `ADMIN_PASSWORD` بكلمة مرور قوية (هذه كلمة دخولك للوحة، والطلاب لا يحتاجونها).
5. **أعد النشر** — تبويب **Deployments** ← أحدث نشر ← **Redeploy** (لازم بعد إضافة قاعدة البيانات والمتغيرات).

> إن كنت تريد رفع فواتير العهد أيضًا: تبويب **Storage** ← **Create Blob Store** ← **Connect**، ثم أعد النشر. منصة الطلاب لا تحتاجه.

### الروابط بعد النشر

بفرض أن نطاقك صار `https://<اسم-المشروع>.vercel.app`:

| الرابط | لمن | ملاحظة |
|---|---|---|
| `https://<نطاقك>/khitta` | **للطلاب** — أرسله في القروب | ثابت، بلا حساب ولا كلمة مرور |
| `https://<نطاقك>/` | لك | لوحة الإدارة — تطلب كلمة المرور |
| `https://<نطاقك>/khitta/<رمز>` | لكل طالب | يُنشأ تلقائيًا بعد حفظ خطته |

رابط الطلاب تلقاه جاهزًا للنسخ في أعلى لوحة التحكم بعد الدخول.

## الإعدادات (`.env`)

| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور الدخول للوحة (الافتراضية `admin123` — **غيّرها فورًا قبل النشر**) |
| `DATABASE_URL` | رابط قاعدة Postgres السحابية (اختياري محليًا، إلزامي على Vercel) |
| `BLOB_READ_WRITE_TOKEN` | مفتاح تخزين الملفات السحابي (يضاف تلقائيًا على Vercel) |
| `AUTH_SECRET` | مفتاح توقيع الجلسات (اختياري) |

## ملاحظات

- استيراد الإكسل يتوقع الأعمدة: **التاريخ، النوع (إيراد/مصروف)، الوصف، التصنيف، المبلغ** — حمّل النموذج الجاهز من صفحة الإيرادات والمصروفات.
- مصروفات العهد المقفلة تظهر في إحصائيات العهد ولا تُضاف تلقائيًا إلى «مجموع المصروفات»؛ إذا رغبت باحتسابها سجلها كحركة مصروف أو استوردها.
- يعمل النظام أيضًا على أي سيرفر عادي (VPS أو جهاز داخلي) بدون أي إعدادات — التخزين حينها محلي في مجلد `data/`.
