# نبغ — خطط الطلاب السنوية

نظام ويب عربي: كل طالب يفتح رابطًا عامًا، يكتب اسمه، ويقسّم المقررات الخمسة على السنة بين **الحفظ** و**الشرح أو القراءة**، وتُحفظ خطته في قاعدة بيانات ترجع لها من لوحة التحكم وتصدّرها إكسل.

## للطالب — رابط عام بلا حساب (`/khitta`)

1. **التعريف** — الاسم (والجوال اختياري)، ثم وحدة التقسيم: **يوميًا** (366 يومًا) أو **أسبوعيًا** (53 أسبوعًا) أو **شهريًا** (13 شهرًا هجريًا).
2. **اختيار المقرر** — «بأي مقرر تحب تبدأ؟».
3. **التقسيم** — لكل مقرر مساران بحجمين مستقلين، يحدّد لكل مسار كم يأخذ في اليوم/الأسبوع/الشهر بأزرار − و + أو بشريط سحب، أو بأزرار جاهزة (على مهل / متوازن / مكثّف). يظهر له فورًا كم فترة يحتاج ومتى يبدأ وينتهي بالهجري والميلادي.
4. **المقررات متتابعة** — الطالب لا يدرس مقررين في وقت واحد؛ كل مقرر يبدأ حيث انتهى الذي قبله، والنصيب الافتراضي يتناسب مع حجم المقرر حتى تسع الخمسة السنة.
5. **المراجعة والحفظ** — لا يقدر يحفظ قبل تقسيم المقررات كلها. بعد الحفظ يحصل على **رابط خاص بخطته** فيه جدول السنة، و**الشروح المعتمدة** لكل مقرر (قرائي وسماعي)، وتحميل الإكسل.

السنة كاملة من 8 ربيع الأول 1448هـ إلى 19 ربيع الأول 1449هـ كما في «الخطة الزمنية» لتمكين 48 (`docs/الخطة-الزمنية.xlsx`)، مستخرجة إلى `src/lib/calendar-data.ts` عبر `scripts/extract-calendar.py`.

## للمشرف — لوحة التحكم (تسجيل دخول بكلمة مرور)

| الصفحة | الوظيفة |
|---|---|
| **الرئيسية** | رابط التسجيل جاهزًا للنسخ، أرقام سريعة (عدد الطلاب، وحدات التقسيم، المقررات)، زر تصدير كل الخطط، وآخر الطلاب مع أزرار إكسل |
| **الطلاب** | القائمة كاملة مع بحث بالاسم أو الجوال، ولكل طالب: عرض خطته، وإكسل «قالب» و«تفصيلي» |
| **صفحة الطالب** | خطته كاملة، ملاحظات المشرف، نسخ رابط خطته، تصدير، وحذف نهائي |
| **المقررات** | اسم المقرر وفنّه ووحدته وحجم كل مسار ومسمّى المسار الثاني، والشرح المعتمد بروابطه، وإضافة أو إيقاف مقرر |
| **الخطة الزمنية** | تقويم السنة كاملًا بألوان الملف الأصلي (مرجع للأحداث) |

### حذف طالب أو خطة

الطالب وخطته شيء واحد: حذفه يحذف خطته معه (`ON DELETE CASCADE`)، ويتوقف رابط خطته وتصديره فيصيران 404. لا يوجد «حذف خطة» منفصل — إن أراد الطالب خطة جديدة يسجّل من رابط التسجيل من جديد.

الحذف من موضعين: زر **حذف** في جدول الطلاب، أو **حذف نهائيًا** في صفحة الطالب. كلاهما يطلب تأكيدًا باسم الطالب قبل التنفيذ، والإلغاء لا يحذف شيئًا. ولا رجعة بعد التأكيد.

وإيقاف مقرر من صفحة المقررات يطلب تأكيدًا كذلك — يخفيه عن الطلاب الجدد ولا يمسّ الخطط المحفوظة.

## التصدير إلى إكسل

- **طالب واحد — قالب** (الافتراضي): نسخة من قالب الخطة الزمنية تبدأ من عنوانها، بألوان موحّدة (الجمعة والسبت رمادي والباقي أبيض)، وقد عُبِّئ تحت كل شهر صفّان: الحفظ ثم الشرح، خانات كل فترة مدموجة واسم المقرر مع أرقام الصفحات. يُبنى بـ `exceljs` (`src/lib/template-xlsx.ts`).
- **طالب واحد — تفصيلي** (`?format=table`): ملخص الخطة، وجدول الخطة صفًا لكل فترة ومقرر، والخطة الزمنية.
- **كل الطلاب**: الطلاب، وتفاصيل الخطط (جاهزة للـ Pivot)، والمقررات، والخطة الزمنية.

الشروح لا تدخل الإكسل — تظهر في صفحة الطالب فقط.

## التشغيل

```bash
npm install
cp .env.example .env   # وغيّر ADMIN_PASSWORD
npm run build
npm start              # http://localhost:3000
```

محليًا تعمل قاعدة Postgres مدمجة (PGlite) في `data/pg` بلا إعداد. على Vercel تُربط قاعدة Neon من تبويب Storage فيُضاف `DATABASE_URL` تلقائيًا، ويُضاف `ADMIN_PASSWORD` من Environment Variables.

| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور اللوحة (الافتراضية `admin123` — غيّرها قبل النشر) |
| `DATABASE_URL` | رابط Postgres السحابي (إلزامي على Vercel) |
| `AUTH_SECRET` | مفتاح توقيع الجلسات (اختياري) |
